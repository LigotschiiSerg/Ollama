# Структурированные PDF-таблицы — Django + Ollama + SQLite

## Что изменилось

- Каждая таблица PDF имеет редактируемое название (`Table.title`). Экспортная физическая SQLite-таблица получает уникальное имя `pdf_<document>_page_<page>_table_<number>_<title>` (не более 45 символов от названия, латиницей).
- Типы: обычная, ключ-значение, многоуровневая шапка. Автоопределение — эвристика; исправляйте вручную, когда определено неверно.
- В таблицах с обычной шапкой первая строка становится именами колонок, **и не дублируется в данных**. В таблицах ключ-значение колонки именуются `field` и `value`, все строки остаются данными.
- Для многоуровневой шапки экспортные колонки выглядят как `Activități didactice | Sem. I`.
- Оригинальная структура ячеек и объединения (если распознаны) хранятся в `documents_cell` и показываются на странице таблицы в Django.
- Изменения в Django обновляют отдельную SQLite-таблицу; прямые изменения физических экспортных SQLite-таблиц **не** синхронизируются обратно в Django. Меняйте данные через Django.

## Установка/обновление Windows

1. Остановите Django и фоновый `process_pdfs` (`Ctrl+C`).
2. **Сделайте резервную копию исходной `db.sqlite3` и папки `media`**.
3. Распакуйте проект в новую папку. Из старого проекта перенесите `db.sqlite3` и `media` в новую папку (при выключенном сервере).
4. Откройте PowerShell в папке с `manage.py`. Создайте окружение при необходимости: `py -3.12 -m venv .venv`, затем `.\\.venv\\Scripts\\Activate.ps1`.
5. `python -m pip install -r requirements.txt`
6. `python manage.py migrate`
7. `python manage.py export_pdf_tables` — перестроить все физические таблицы **без повторного OCR**.
8. `python manage.py runserver` — открыть http://127.0.0.1:8000/
9. В другом терминале: `.\\.venv\\Scripts\\Activate.ps1`; `python manage.py process_pdfs --watch`.

После изменения названия или структуры шапки на странице таблицы Django нажмите «Сохранить настройки». Физическая SQLite-таблица обновится автоматически.

## Ограничения

- Вывод Ollama неточен: для многоуровневых таблиц, в том числе с вложенными объединениями, модель может не распознать `rowspan`/`colspan`; в этом случае оригинальная визуальная структура не гарантирована. Старые распознанные таблицы с утраченными объединениями **нельзя восстановить без повторной проверки PDF**.
- Для старых данных без сохранённого названия экспортные имена получают суффикс `untitled`. Название можно отредактировать в Django.
- Автоматическое определение числа строк заголовка консервативно. Для таблиц, где первая строка — данные, установите соответствующий тип и заголовок вручную.
- SQLite не поддерживает визуальные объединения ячеек — они отображаются в Django, в SQLite структура заголовков «сплющивается».
- Таблицы `pdf_*` пересоздаются при экспорте; **не используйте их как источник редактирования**.
- Приложение предназначено для локального использования, без авторизации. Не публикуйте его без дополнительной защиты.
