# PDF Desk: Docling/TableFormer + SQLite + опциональная Ollama

## Установка (Windows, Python 3.11–3.12)

```powershell
py -3.12 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py test documents
```

Первый запуск Docling скачает модели и может быть продолжительным. OCR и TableFormer работают на CPU, GPU полезен, но не обязателен. Для больших PDF и слабого ПК понадобится память; скорость заранее не гарантируется.

Терминал 1: `python manage.py runserver`.

Терминал 2: `python manage.py process_pdfs --watch`.

Откройте http://127.0.0.1:8000/ и загрузите PDF. Для распознавания новых PDF используется Docling, в том числе TableFormer для геометрии, OCR для текста и модели объединений ячеек. Ollama по умолчанию не вызывается. Чтобы включить старый метод: `$env:PDF_ENGINE='ollama'` перед запуском обработчика.

**Безопасность старых результатов:** старые страницы остаются в базе и пропускаются. Для повторного извлечения выбранных страниц сначала сделайте резервную копию базы и папки media. Затем удалите записи конкретных Page через Django shell, только если уверены, что хотите заменить их результаты. Не удаляйте базу целиком.

**Ограничения:** TableFormer может ошибаться в объединениях и заголовках. Требуется сверка с оригиналом; не обещается точная реконструкция всех таблиц. Docling обрабатывает весь документ за один вызов, поэтому после старта не показывает прогресс по каждой странице до завершения конвертации. При большом документе сначала протестируйте 1–2 страницы на копии PDF.

Структуры `rowspan`/`colspan` сохраняются в `documents_cell`, а отдельные плоские SQLite-таблицы строятся из той же сетки. Редактирование названий и `header_rows` есть в веб-интерфейсе. Запускать неавторизованный сайт только локально.

## Исправление сложных таблиц на страницах 14–16

Добавлен необязательный OpenCV для обнаружения крупных таблиц с видимыми линиями.
Если Docling не нашёл таблицу на странице, приложение проверяет линейную сетку и
повторно распознаёт её отдельно как PDF-фрагмент. Если и это не получилось,
страница отмечается ошибкой вместо сохранения как якобы полностью распознанной.
Качество извлечения необходимо проверить по оригиналу; текст ячеек и объединения
могут оставаться неверными. Для таблиц без линий автоматического восстановления нет.

После установки и создания резервной копии базы:

```powershell
python -m pip install -r requirements.txt
$env:PDF_ENGINE = "docling"
python manage.py process_pdfs --document 2 --pages 14-16
```

Замените 2 на реальный ID документа. Команда НЕ распознаёт остальные страницы и
не удаляет их; содержимое каждой выбранной страницы меняется только после
валидного результата и успешного завершения транзакции записи.

Важно: связи между частями многостраничных таблиц пока не устанавливаются
автоматически, и большие таблицы остаются отдельными по страницам. Проверяйте
повторяющиеся заголовки и перенос строк вручную.
