# Реальные таблицы PDF в SQLite

## Что изменилось

Раньше все значения находились в `documents_cell`. Теперь **каждая таблица PDF** дополнительно создаётся в SQLite как **отдельная физическая таблица**:

- `pdf_2_page_01_table_01`
- `pdf_2_page_01_table_02`
- `pdf_2_page_02_table_01`

В **DB Browser for SQLite → Browse Data** можно выбрать её в выпадающем списке и увидеть обычные столбцы/строки. Первую строку PDF программа использует как подписи колонок **и сохраняет её как строку данных**: это сохраняет данные даже в таблицах без заголовков. `_row_no` — порядковый номер строки. Повторяющиеся и пустые заголовки автоматически получают уникальные имена.

Исходные `documents_table` / `documents_cell` остаются внутренним хранилищем Django, чтобы работало редактирование ячеек и не потерялись старые документы. При изменении ячейки через интерфейс физическая таблица пересоздаётся и синхронизируется. **Изменения, сделанные непосредственно в DB Browser, не синхронизируются обратно в Django**. Редактируйте через интерфейс приложения.

## Восстановить таблицы из УЖЕ обработанных PDF, без Ollama

Скопируйте прежние `db.sqlite3` и `media/` в папку обновлённого проекта (с остановленными Django и воркером). Сделайте резервную копию БД.

В активированном `.venv` выполните:

```powershell
python manage.py migrate
python manage.py export_pdf_tables
```

Команда построит отдельную SQLite-таблицу для **каждой уже распознанной PDF-таблицы**. Не требуется перераспознавание или изменение статуса документов. Для новых страниц таблицы создаются автоматически при сохранении.

```powershell
python manage.py runserver
```

В другом терминале:

```powershell
.\.venv\Scripts\Activate.ps1
python manage.py process_pdfs --watch
```

## Ограничения

- Этот способ меняет **формат хранения и отображения**, а не качество распознавания. Ошибки и пропущенные строки Ollama остаются ошибками.
- Объединённые ячейки физической таблицы SQLite отображаются как простые значения в позиции верхней левой ячейки. Оригинальные `rowspan/colspan` сохраняются в `documents_cell`.
- При повторном распознавании страницы её соответствующие физические таблицы заменяются. Не редактируйте их напрямую в DB Browser.
- Нужен SQLite (не MySQL/MariaDB). Для больших PDF действуют ограничения по количеству колонок и строк.
- Проект тестировался проверкой синтаксиса; полный Django-тест здесь не запускался из-за отсутствия Django. Проверьте `python manage.py check` и `python manage.py test documents` у себя.
